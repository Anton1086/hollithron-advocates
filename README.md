# Hollithron Advocates, P.C.

Modern website for the Denver immigration law practice at [hollithronadvocates.com](http://hollithronadvocates.com/).

## Stack

- Next.js (App Router)
- Tailwind CSS
- English and Spanish routes

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Spanish pages live under `/es`.

## Notes

- The contact form opens a `mailto:` draft to `matters@hollithronadvocates.com`.
- Office visit copy was updated from pandemic-era language while keeping the same practical policies.
- Brand photos and contact information come from the existing site.
